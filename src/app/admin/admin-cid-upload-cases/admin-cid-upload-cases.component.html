Excel Upload Instructions
Important: Please read all instructions carefully before uploading your file.
File Specifications
  • Total Fields 28
  • Download the sample Excel template first
  • Save in .xlsx format only
  • Don't modify column headers
Mandatory Fields
  • ★ Sub-Division (अनुमंडल)
  • ★ Circle
  • ★ Police Station (थाना)
  • ★ Case Number (प्रकरण संख्या)
  • ★ Case Date (तिथि)
  • ★ I.O. Name & Designation
Accused Information Requirements
  • Accused Entry Name
  • Age
  • Father's Name
Ensure accused details match FIR records exactly
Upload Process
  1. Select SR/NSR type from dropdown
  2. Choose your District
  3. Select preferred language (Hindi/English)
  4. Click "Choose File" to select your completed Excel
  5. Verify all mandatory fields are completed
  6. Click "Upload Submit" for processing
